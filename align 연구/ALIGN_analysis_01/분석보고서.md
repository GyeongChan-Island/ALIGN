# ALIGN 센서 기울기 수집 연습 결과

이번 데이터는 사용자가 **센서를 손으로 기울여 수집**했다고 확인한 자료입니다. 정상/불량 라벨은 연습용 지정값입니다. 실제 착용자의 정상/불량 자세를 검증한 데이터로 해석하지 않습니다.

## 수집 상태

- 원본: Labeling_practice_01_5_5.zip. CSV 10개, summary 10개, events 10개.
- 피험자 표기 P01, 라벨 0과 1 각각 5세션. 실제 인체 착용 실험은 아님.
- 총 5,011행: 라벨 0은 2,505행, 라벨 1은 2,506행.
- 9세션은 501행, 1세션은 502행. 모든 세션 약 10초, 약 50Hz.
- 원시 CSV에서 순번·시간 증가, 열 구조, 라벨 일관성, 유한 숫자를 재검사했으며 요약 파일의 행 수·주파수·누락·시간 이상·포화 경고 집계와 대조했습니다.
- 누락 0, 보고된 형식 오류 0, 보고된 읽기 실패 0, 시간 이상 0, 포화 근접 행 0. 요약 warnings 모두 비어 있음.
- 서로 다른 세션 ID와 파일 해시를 확인했습니다. 단, 해시가 다르다는 사실만으로 모든 실험이 독립적으로 수행됐음을 보증하지는 않습니다.

## 센서값의 차이

signal_overview.png는 각 라벨의 5세션을 겹쳐 보여줍니다. 두 가속도 벡터 사이의 각도와 각 센서 자이로 벡터 크기를 표시했습니다. session_means.png는 각 세션의 가속도 평균을 비교합니다.

라벨 0과 1의 센서값에 차이가 있고, 라벨 1은 세션마다 기울인 축과 움직임이 달라 보입니다. 이는 손으로 기울였다는 실험 설명과 부합합니다. 측정 중 회전이 포함되어 있어 ‘정지한 자세만 유지한 데이터’로 간주할 수 없습니다.

가속도 벡터 간 각도는 중력과 움직임, 센서 축 및 장착 방향의 영향을 받습니다. 여기서는 신호를 비교하는 지표일 뿐이며 흉추·요추의 해부학적 각도나 임상적 자세 기준을 뜻하지 않습니다.

## 간단한 분류 실험

복잡한 모델이나 특징 선택 없이 미리 정한 단순 기준선을 적용했습니다.

1. 각 세션 안에서 연속 50행을 하나의 약 1초 구간으로 묶었습니다. 구간은 겹치지 않으며 세션 경계를 넘지 않습니다. 각 세션 끝의 1~2행은 구간을 구성하지 못하므로 모델 입력에서만 제외했습니다. 원본은 변경하지 않았습니다.
2. 각 구간의 12채널 평균을 특징으로 사용했습니다. 시간, 순번, 라벨, 세션 ID, P01은 특징에 넣지 않았습니다.
3. 각 라벨의 세션을 시간순으로 정렬했습니다. 1번째 정상/불량 쌍부터 5번째 쌍까지 차례로 평가용으로 남겨 5회 평가했습니다. 매 회 8세션 학습, 2세션 평가입니다.
4. 매 회 학습 구간에서만 채널 평균·표준편차를 구해 표준화하고, 라벨별 특징 중심을 학습했습니다. 평가 구간은 유클리드 거리가 더 가까운 중심의 라벨로 분류했습니다. 하이퍼파라미터 조정이나 결과를 본 뒤의 모델 선택은 하지 않았습니다.

| 실제 라벨 | 예측 0 | 예측 1 |
|---|---:|---:|
| 0 | 50 | 0 |
| 1 | 13 | 37 |

- 평가 구간: 총 100개, 라벨별 50개.
- 구간 정확도: **87/100 = 87%**.
- 라벨 0 재현율: 100%, 라벨 1 재현율: 74%.
- 회차별 정확도: 75%, 100%, 100%, 75%, 85%.
- 세션 내 구간 다수결: 10세션 중 8세션 정답. 나머지 2세션은 5:5 동률로 판정 보류하며 정답에 포함하지 않았습니다.

이 수치는 **같은 환경에서 손으로 기울인 센서 신호를 구분한 예비 결과**입니다. 실제 착용자의 자세교정 정확도는 아닙니다. 동일 세션의 구간은 서로 연관되므로 100구간을 100개의 독립 인체 실험처럼 해석하지 않습니다. 데이터는 동일 ID, 동일 날짜의 소규모 자료이며 새 사람·새 장착·새 날짜에 대한 성능은 평가하지 않았습니다.

## 다음 실험

1. 현재 자료를 ‘손 기울기 연습’으로 따로 보관합니다. 실제 착용 자료와 같은 학습 집합에 무심코 합치지 않습니다.
2. 실제 착용 시 IMU1은 흉추, IMU2는 요추의 정한 위치에 고정하고 센서 축 방향과 장착 방법을 기록합니다.
3. 정상/불량 자세의 관찰 가능한 기준을 먼저 정합니다. 각 세션에서 어떤 자세를 취했는지 실험 기록으로 남깁니다.
4. 자세를 먼저 잡고 안정화한 뒤 10초 수집합니다. 정적 자세를 분류하려면 측정 중 자세 전환이나 센서 조작을 피합니다. 걷기 등 동작 중 분류가 목적이면 별도 프로토콜과 라벨을 만듭니다.
5. 같은 P01을 사용해도 되지만 착용 실험은 별도 저장 폴더를 사용합니다. 예: 명령 뒤에 `--out "D:\ALIGN_body_data"` 추가. 정상/불량을 번갈아 수집하여 순서와 시간에 따른 영향을 줄입니다.
6. 여러 독립 세션, 다른 날짜와 재장착 조건을 추가합니다. 새 사람에 대한 성능은 여러 사람의 데이터를 모은 뒤 피험자를 통째로 남겨 평가합니다.

## 결과 파일

- session_audit.csv: 세션별 수집 상태와 평가 결과.
- window_predictions.csv: 각 평가 구간의 실제/예측 라벨.
- analysis.json: 방법, 원본 해시, 회차별 학습/평가 세션 목록, 수치 및 그래프에 사용한 값.
- signal_overview.png, session_means.png: 확인용 그림.

원본 ZIP과 센서 CSV는 수정하지 않았습니다. 이 보고서에는 배포용 또는 검증된 자세교정 모델이 포함되지 않습니다.
