# data

측정 데이터 폴더입니다. 형식은 데이터 로거(`ALIGN_logger.ino` + `collect_csv.py`, PR #3)가 실제로 저장하는 형식을 따릅니다. 이 형식에서 벗어난 CSV는 학습 스크립트(`train_model.py`)가 거부합니다.

## 세션 하나 = 파일 3개

`collect_csv.py`를 한 번 실행하면 한 세션이 기록되고, 같은 이름으로 파일 3개가 생깁니다.

```
<피험자>_<YYYYMMDD>_<HHMMSS>_<8자리 hex>_label<0|1>.csv            센서 값
<피험자>_<YYYYMMDD>_<HHMMSS>_<8자리 hex>_label<0|1>.summary.json   수집 품질 요약
<피험자>_<YYYYMMDD>_<HHMMSS>_<8자리 hex>_label<0|1>.events.txt     로거 메시지·오류 기록
예: P01_20261113_152557_db3c0163_label1.csv
```

- **피험자**: 실명 대신 `P01`, `P02`, `P03` 같은 코드(영문·숫자·`_`·`-`, 40자 이내)를 씁니다. 저장소가 Public입니다.
- **세션 ID**: `<날짜>_<시각>_<랜덤 8자리>`로 자동 생성됩니다. 세션 하나는 한 라벨만 가집니다.
- 파일은 덮어쓰지 않고 항상 새로 만듭니다.

## CSV 열 (17개)

| 열 | 단위 | 설명 |
| --- | --- | --- |
| `session_id` | - | 세션 ID (파일 안에서 모두 같음) |
| `subject_id` | - | 피험자 코드 |
| `label` | - | `0` 또는 `1` (아래 라벨 참고) |
| `seq` | - | 수집 시작(`S` 명령) 후 20ms 슬롯 번호. 건너뛴 슬롯도 번호를 쓰므로 번호가 비면 누락 |
| `time_us` | µs | ESP32 부팅 후 시간(`esp_timer`), 두 센서를 읽기 시작한 시각 |
| `imu1_ax_g`, `imu1_ay_g`, `imu1_az_g` | g | IMU 1(0x68, 흉추) 가속도. **중력 포함** |
| `imu1_gx_dps`, `imu1_gy_dps`, `imu1_gz_dps` | °/s | IMU 1 각속도 |
| `imu2_ax_g` … `imu2_gz_dps` | g, °/s | IMU 2(0x69, 요추), 순서는 IMU 1과 같음 |

각도(상대 각도 등)는 CSV에 저장하지 않고, 분석·학습 단계에서 원시값으로 계산합니다.

## 센서 설정

| 항목 | 값 |
| --- | --- |
| 샘플링 | 50Hz (내부 1kHz ÷ 20) |
| 저역통과 필터 | DLPF 3 (약 44Hz) |
| 범위 | 가속도 ±2g, 자이로 ±250°/s |
| I2C | 400kHz, SDA 21 / SCL 22 |
| 시리얼 | 115200 baud, PC에서 `S` 보내면 시작 / `X` 보내면 중지 |

## 라벨

| 값 | 의미 |
| --- | --- |
| `0` | 바른(정상) 자세 |
| `1` | 불량 자세 |

지금 로거는 0/1 두 값만 받습니다. 물건 줍기·기지개 같은 일시 동작을 따로 구분하려면 3차 실습 전에 라벨을 늘리거나, 영상 기반 구간 라벨 파일을 따로 두는 방식을 정해야 합니다 (미정).

## summary.json에서 볼 것

| 필드 | 정상 기준 |
| --- | --- |
| `received_hz` | 49 ~ 51 |
| `missing_slots` | 0 (순번 누락 수) |
| `malformed`, `read_fail_messages` | 0 (형식 오류 줄, 센서 읽기 실패) |
| `timing_anomalies` | 0 (샘플 간격이 20ms에서 5ms 넘게 벗어난 횟수) |
| `near_full_scale_rows` | 0 (가속도 1.98g 또는 자이로 247.5°/s 이상인 행, 포화 의심) |
| `warnings` | 빈 목록 |
| `reason` | `duration_complete` (끝까지 수집됨) |

경고가 있는 세션은 지우지 말고 그대로 두되, 학습에 쓸지 팀에서 판단합니다.

## 학습할 때 쓰는 단위

학습·실시간 판정 코드는 같은 세션 안의 **연속 50행(약 1초)**을 겹치지 않게 묶어 한 구간으로 씁니다. 누락·시간 이상·포화가 생기면 그 구간은 버리고 새로 모읍니다. 평가할 때는 같은 세션(나중에는 같은 사람)이 학습과 평가에 섞이지 않게 나눕니다.
