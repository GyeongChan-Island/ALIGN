\# ALIGN AI Model Development Plan



\## Goal

Develop a deep learning model to classify posture using two IMU sensors.



\## Hardware

\- XIAO ESP32-S3

\- Two MPU-6050 sensors

\- DRV2605L vibration driver



\## AI Model

\- Input: Acceleration and gyroscope data

\- Sampling target: 50 Hz

\- Model: 1D CNN

\- Output: Posture classification



\## Current Status

\- Arduino environment configured

\- Initial Python data practice completed

\- Real sensor data collection not started
