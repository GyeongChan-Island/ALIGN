## 알려진 문제

1. **빈 센서 세션 포함**: `20261113_180239_b5f86fa7`(정상)은 IMU2 6채널이 1001행 전부 0입니다. summary 경고 없이 저장돼 학습에 들어갔고, 정상 오판 22건 중 20건이 이 세션에서 나왔습니다. ALIGN-data `sessions.csv`에서 `exclude`로 표시했습니다.
2. **측정 순서**: 정상 10세션을 먼저, 불량 10세션을 나중에 몰아서 측정해 자세 차이와 시간에 따른 변화(센서 온도, 조끼 밀림)가 섞였을 수 있습니다.
3. 같은 사람(P01)의 세션 간 평가이며, 새 사람에 대한 성능이 아닙니다.

원인 분석과 조치는 노션 🐞 트러블슈팅 "P01 착용 첫 세션에서 IMU2(요추) 값이 20초 내내 전부 0"에 있습니다.
