# 실습 계획과 목표 지표

1차 실습(11/08)에서 개발환경 세팅과 MPU6050 2개 동시 연결·데이터 수신까지 끝났습니다. 남은 실습 2~3회로 프로젝트를 마무리합니다. 아래 목표 수치는 모두 **제안값**이며, 2차 실습 예비 데이터를 보고 확정합니다.

원칙: 실습 시간에는 같이 있어야 하는 일(하드웨어, 착용 실험, 촬영)만 하고, 코드 작성·분석은 실습 사이에 각자 합니다.

| 실습 | 단계 | 핵심 산출물 |
| --- | --- | --- |
| 2차 | 캘리브레이션 + 자세 추정 | 두 센서 상대 각도 CSV, 불량 기준 초안 |
| 3차 | 조끼 장착 + 본 데이터 수집 | 라벨 붙은 착용 데이터 60분 이상 |
| 실습 밖 | AI 모델 | 판정 방식 3종 구현 + 1차 결과 |
| 4차 | 평가 + 피드백 | 최종 비교표, DRV2605L 진동 데모 |

## 2차: 캘리브레이션 + 자세 추정

실습 전 준비: 상보 필터 코드 초안, PC 쪽 Python 로거(시리얼 → 타임스탬프 포함 CSV)

1. 센서별 자이로 바이어스 측정·보정 (정지 상태 평균값 빼기)
2. 가속도 기반 Roll/Pitch 계산 → 상보 필터로 자이로와 결합
3. 장착 위치·좌표계 정의 (IMU1 0x68 = 흉추, IMU2 0x69 = 요추)
4. 상대 각도 = 흉추 pitch − 요추 pitch
5. 정적 검증: 0°/30°/60°/90°로 기울여 휴대폰 기울기 앱 값과 비교
6. 몸에 임시 고정 후 10분 예비 착용 → 불량 기준 각도·지속시간 초안

성과지표:

- [ ] 바이어스 보정 후 정지 상태 자이로 ±0.3°/s 이내
- [ ] 정적 각도 오차 ±3° 이내
- [ ] 5분 정지 시 각도 드리프트 2° 이내
- [ ] 두 센서 모두 50Hz 이상, 10분간 끊김 없이 CSV 저장
- [ ] 캘리브레이션 절차(바른 자세 5초 → 0° 설정) + 불량 기준 초안 문서화

## 3차: 조끼 장착 + 본 데이터 수집

- 3명이 각자 조끼 착용 후 20~30분 책상 작업
  - 지속 불량: 구부정하게 앉기, 거북목 — 회당 30초 이상, 1인 5회 이상
  - 일시 동작: 물건 줍기, 신발 끈 묶기, 기지개, 뒤돌아보기 — 동작별 1인 10회 이상
- 휴대폰 동시 촬영(목 아래만). 시작할 때 몸통을 3번 두드려 동기화 신호를 남김
- 영상을 보며 시작·끝 시각과 동작을 라벨링 ([data/README.md](../data/README.md) 형식)

성과지표:

- [ ] 총 착용 데이터 60분 이상 (3명 × 20분 이상)
- [ ] 일시 동작 120회 이상 (4종 × 10회 × 3명)
- [ ] 지속 불량 구간 15회 이상
- [ ] 전체 라벨 완료, 동기화 오차 0.5초 이내

## 실습 밖: 판정 방식 3종

- ① 기준선: 흉추 센서 1개 + 각도·지속시간
- ② 두 지점 상대 각도 + 지속시간 규칙
- ③ 윈도우 특징(평균·분산·기울기 등) 또는 1D CNN 분류기
- 평가: 1명 빼고 학습 → 그 1명으로 테스트, 3명 돌아가며 반복 (같은 사람으로 학습·테스트하면 점수가 부풀려짐)

## 4차: 평가 + 진동 피드백

1. 결과표·혼동행렬 검토, 오탐 장면은 영상으로 재확인
2. 부족했던 동작만 재수집
3. DRV2605L + 진동 모터 연결, ② 규칙 판정 → 진동 알림 실시간 데모
4. 결과보고서용 사진·영상 촬영
