## 배선

두 IMU는 SDA·SCL을 함께 쓰는 병렬 연결입니다. MPU6050의 I2C 주소는 0x68 / 0x69 중 하나라서 AD0 핀을 다르게 연결해 주소를 나눕니다.

| ESP32 | IMU 1 (흉추) | IMU 2 (요추) | DRV2605L (예정, 미테스트) |
| --- | --- | --- | --- |
| 3V3 | VCC | VCC | VIN |
| GND | GND | GND | GND |
| GPIO 21 | SDA | SDA | SDA |
| GPIO 22 | SCL | SCL | SCL |
| - | AD0 → GND | AD0 → 3V3 | - |

| 장치 | I2C 주소 |
| --- | --- |
| IMU 1 (흉추) | `0x68` |
| IMU 2 (요추) | `0x69` |
| DRV2605L | `0x5A` (고정) |

주의:

- MPU6050의 VCC는 5V가 아니라 ESP32의 **3V3**에 연결합니다.
- 배선을 바꿀 때는 USB를 먼저 뽑습니다.
- 브레드보드 두 개를 쓸 때는 GND와 전원 레일을 점퍼선으로 따로 이어야 합니다. 나란히 붙어 있다고 연결된 것이 아닙니다.
- 납땜할 때 옆 핀끼리 붙으면 포트가 잡혔다 끊겼다를 반복합니다.

## 센서 장착과 좌표계

- IMU 1 (0x68): 흉추(상부 등)
- IMU 2 (0x69): 요추(허리)
- 상대 각도 = 흉추 pitch − 요추 pitch
- 몸의 앞뒤 방향 축은 2차 실습에서 확정해 이 문서에 추가합니다.

## 측정값 참고 (1차 실습)

정지 상태에서 가속도는 X ≈ 0.09g, Y ≈ 0.02g, Z ≈ 1.02g로 크기가 약 1g라 정상입니다. 자이로는 가만히 둬도 ±1~2°/s 흔들리므로 바이어스 보정(정지 상태 평균값 빼기)이 필요합니다.

기본 설정 기준 단위 변환:

| 값 | 범위 | 변환 |
| --- | --- | --- |
| 가속도 | ±2g | raw / 16384.0 → g |
| 자이로 | ±250°/s | raw / 131.0 → °/s |
| 온도 | - | raw / 340.0 + 36.53 → °C |
